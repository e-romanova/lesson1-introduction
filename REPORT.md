# Отчёт: Урок 1 — основы PyTorch

## Цель работы

Научиться создавать тензоры и выполнять операции над ними, использовать автоматическое дифференцирование PyTorch и сравнивать время выполнения операций на CPU и CUDA.

## Задание 1. Создание и манипуляции с тензорами

В `homework_tensors.py` реализованы создание случайного тензора 3x4, нулевого тензора 2x3x4, тензора единиц 5x5 и матрицы 4x4 с числами от 0 до 15. Также показаны транспонирование, матричное и поэлементное умножение, сумма элементов, индексация 3D тензора и преобразование формы тензора из 24 элементов.

Для примера матрица A содержит числа 1..12 в форме 3x4. Поэтому сумма её элементов равна 78. Результат `A @ B` имеет форму 3x3, а `A * B.T` — форму 3x4.

## Задание 2. Автоматическое дифференцирование

В `homework_autograd.py` вычислены градиенты функции `f(x,y,z)=x²+y²+z²+2xyz`, реализована MSE для линейной модели `y_pred=w*x+b`, а также проверено цепное правило для `sin(x²+1)`.

Для x=1, y=2, z=3 значение функции равно 26, а производные равны `df/dx=14`, `df/dy=8`, `df/dz=10`. Производная функции `sin(x²+1)` сравнивается с результатом `torch.autograd.grad`; проверка завершается утверждением, если значения совпадают с небольшой численной погрешностью.

## Задание 3. Производительность CPU и CUDA

Скрипт `homework_performance.py` измеряет матричное умножение, сложение, поэлементное умножение, транспонирование и сумму элементов. Для CPU используется `time.perf_counter()`, для CUDA — события `torch.cuda.Event` с синхронизацией. Рассчитывается ускорение `CPU time / GPU time`, если доступны измерения на обоих устройствах.

В окружении, в котором подготовлен этот проект, PyTorch доступен в CPU-сборке, CUDA недоступна. Поэтому GPU-результаты здесь не приводятся, чтобы не выдавать предполагаемые значения за измерения. При запуске на компьютере с CUDA скрипт автоматически добавит GPU-замеры. По умолчанию используется быстрый режим, чтобы избежать длительного запуска; `python homework_performance.py --full` запускает заданные в условии размеры `(64,1024,1024)`, `(128,512,512)` и `(256,256,256)`. Полный режим может потребовать значительной памяти и времени.

## Выводы

Тензоры PyTorch поддерживают многомерные данные и операции над ними. `reshape` меняет форму при сохранении количества элементов; `@` выполняет матричное умножение, а `*` — поэлементное. Autograd позволяет получать производные без ручного программирования цепочки дифференцирования, а аналитические формулы полезны для проверки. GPU не гарантирует ускорения для любой задачи: итог зависит от размера данных, характера операции, устройства и накладных расходов на запуск и передачу данных.

## Воспроизводимость

Используется `torch.manual_seed(42)` в задании 1. Установите зависимости из `requirements.txt`, затем запустите:

```bash
python homework_tensors.py
python homework_autograd.py
python homework_performance.py
```

Для точных больших размеров третьего задания выполните `python homework_performance.py --full`. Измеренные результаты сохраняются в `performance_results.json`. Время выполнения зависит от аппаратного обеспечения, версии PyTorch и загрузки системы.
